# TimeBox

Конструктор видеоигр. Первый урок — песочница **«Лови яблоки»**: сверху падают яблоки, внизу
ездит корзина, а ученик по шагам пишет код игры на JavaScript. Слева код по вкладкам и гайд,
справа игра.

## Запуск

```bash
npm install
npm run dev        # http://localhost:5173
```

`?finished` — готовая версия игры (бомба, звезда, +10 очков, ускорение) со своим сохранением.

## Скрипты

| Команда             | Что делает                                                    |
| ------------------- | ------------------------------------------------------------- |
| `npm run dev`       | дев-сервер Vite                                               |
| `npm run build`     | проверка типов + сборка в один файл `dist/index.html`         |
| `npm test`          | юнит-тесты (Vitest): склейка, синтаксис, переводы, логика игры |
| `npm run test:e2e`  | сборка + сквозные проверки (Playwright) на `dist/index.html`  |
| `npm run check`     | линтер, сборка и юнит-тесты                                   |
| `npm run lint`      | линтер (oxlint)                                               |
| `npm run preview`   | локальный просмотр собранного `dist/`                         |

`dist/index.html` — один файл со всем внутри (код, стили, шрифты): его можно открыть с
флешки без интернета.

## Что умеет

- Код по вкладкам «Движок → Герой → Яблоки → Поимка», у каждой вкладки своя история отмены.
- Гайд по шагам с кнопками «Вставить», задания на улучшение, бомба и звезда по частям.
- Ошибки с вкладкой и строкой на понятном языке; синтаксис проверяется ещё во время печати.
- Подсказки к именам движка (автодополнение и при наведении мыши).
- «Приборы» (значения переменных), консоль для `console.log`, пауза, шаг по кадрам,
  замедление, показ зоны поимки.
- Стабильные 60 кадров на мониторах 120/144 Гц, чёткий холст на Retina.
- Сбросы с подтверждением и отменой, сохранение в браузере, рекорд.
- Ссылка на свою игру, скачивание игры одним файлом, экспорт и импорт кода.
- Режим проектора (светлая тема), размер шрифта кода, экранные стрелки для планшетов.

## Структура

```
src/
  main.tsx, App.tsx       точка входа и раскладка
  app/                    контроллер (вся логика) и маленький внешний стор
  core/                   чистые модули: склейка, синтаксис, переводы ошибок, прогресс
  lessons/catch/          урок «Лови яблоки»: код вкладок, гайд, подсказки
  sandbox/                обвязка iframe (runtime.js), сохранение, обмен кодом
  editor/                 CodeMirror: вкладки, тема, подсказки
  components/             интерфейс
  styles/                 токены, база, общие примитивы
  assets/fonts/           Onest и JetBrains Mono (woff2, OFL)
tests/unit/               Vitest
tests/e2e/                Playwright
docs/SPEC.md              ТЗ
docs/PLAN.md              план и предложения
```

Импорты из `src` можно писать через алиас `@/`, например `import App from '@/App'`.
Модули `src/core` импортируют друг друга относительными путями — их можно запускать в Node напрямую.
